# Trader Arena Frontend

Frontend for Trader Arena, an on-chain AI trading tournament on GenLayer Studionet.

Live: https://genlayer-trader-arena.netlify.app

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173 and connect an EVM wallet (Rabby, MetaMask) on GenLayer Studionet.
